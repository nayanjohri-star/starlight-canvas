# MiniMax 功能对照与操作验收

参照为本机 MiniMax Design 导演插件 0.24.10；其代码、人物素材和桌面服务不随本包分发。CozyClay 底座锁定 `4226099b42958b9d76ef390aa067d2449d3c2994`，iFrame 模块参照锁定 `7a85c231c0d13a8842b51a795b1aa1bc20345ccf`。下表对应本轮网页版范围，不承诺复制 MiniMax 桌面宿主的全部能力。

表中的步骤和用例定义验收路径，不能单凭此表认定候选通过。实际结果以相同候选 SHA 的独立报告、浏览器与媒体证据为准；软件渲染功能结果和真实显卡性能结果分别记录。

| 对照项 | 网页版操作路径与通过标准 | 主要验证 |
| --- | --- | --- |
| 中文工作台 | 从已登录画布打开导演台；对象树、属性、真实视口及时间轴可调整、折叠和最大化，输入焦点稳定。 | `hosted-director-operations-ui`、`hosted-director-v04` |
| 对象编辑 | 添加基础几何体和道具；普通点击及 Ctrl 多选、分组、继承锁、隐藏、复制、删除；一次拖动可一步撤销并重做。 | 对象 UI 用例及编辑器域测试 |
| 双角色调姿 | 分别选择两个人物，拖手脚 IK、固定脚、镜像、重置、保存姿态、复用；不能误改另一人物，刷新后结果保留。 | 双人物 UI、IK 历史与持久化测试 |
| 动作与走位 | 设置路径、速度和停顿，再应用离线站立、行走或挥手；兼容 BVH、FBX、NPZ 导入。不支持的骨架明确列缺失映射。 | 动作域、导入轴转换及双人物 UI |
| 模型与背景 | 导入自包含 GLB 和背景图；恢复模型、贴图与稳定素材身份；损坏、外部依赖和缺失资源定位到对象。 | 场景资产、完整工程和迁移测试 |
| 机位与摄影 | 自由、俯视及成片视角；三个独立机位的切换、绑定、复制与删除；画幅、焦距、视场角、对焦及景深一致。 | 摄影机域、相机 UI、真实深度与媒体测试 |
| 摄影机运动 | 在同一镜头数据上设置推拉、横移、升降、环绕、跟随和关键帧；视口与导出使用同一逐帧计算。 | 摄影机求值、边界与随机跳帧测试 |
| 时间轴 | 24/30 fps 整数帧；逐帧、播放、关键帧操作和镜头切换；6.25 秒在 24 fps 下为 150 帧，在 30 fps 下界面说明取整为 188 帧。 | 时间轴域、相机 UI及真实 MP4 时间戳 |
| 干净输出 | PNG、首尾帧、720p/1080p H.264、逐镜头参考包；无网格、关节标记及界面，慢编码和后台标签页不延长成片。 | 原生产管线媒体矩阵、逐帧状态及解码检查 |
| 导出控制 | 普通按钮取消；失败无成功素材；取消后可再次导出，资源释放，整批输出原子发布。 | 导出异常与真实按钮测试、宿主原子批次测试 |
| 工程与恢复 | 宿主保存修订与完整工程包下载分别标示；刷新、关闭、切项目和干净浏览器导入后可继续编辑；失败保留完整修订，未知版本保留原档。 | 保存竞态、实际 UI、迁移及 20 次生命周期 |
| 星光画布接入 | 通过实际 `/canvas/` 路由运行；首次画布不加载完整导演台；输出成为当前项目素材，原图、首尾帧与视频保持编号和引用顺序。 | 托管安装、生成 UI 和发布包验收 |
| 模型辅助 | 用户主动报价、确认、预览、放弃或一步应用提案，撤销不重新调用；正常编辑与输出零模型调用。 | 提案实际 UI、宿主和后端费用边界 |
| 生成恢复 | 模拟丢失已接受响应、查询和下载失败后恢复；只查询已接受任务。指定预算的真实供应商短片单独记录质量和费用。 | 生成 UI、任务恢复及独立供应商记录 |

移动端查看与工程访问不等于完整触控编辑。MiniMax 手机虚拟摄影机、传感器动捕、专用桌面服务，以及需要额外 GPU 服务的动作生成属于扩展项。本轮不以这些服务作为摆场、调姿、离线动作或导出的前置条件。
