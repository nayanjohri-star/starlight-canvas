## 本地智能画布使用

源码位于 `frontend/canvas/`。在已安装 Node.js 的本机运行：

```powershell
Set-Location 'E:\codex workspace\project_021_中转站搭建\frontend\canvas'
npm run build
npm start
```

用 Chrome 打开 `http://127.0.0.1:4178`，点击右上角密钥按钮输入本站密钥。左侧“创建”添加节点或模板，“素材”上传文件并点“＋节点”；把素材输出连到视频节点，再选择型号和参考模式。参数区显示标准单价预估，实际可用型号以该密钥校验结果为准。

顶栏“黑色／白色”可随时切换主题，浏览器会记住选择。选中视频节点后可在“模型”中切换当前密钥允许的型号；保留提示词和已连接素材，各型号分别记住参数，素材超限或不兼容时会提示并阻止提交。参数区的素材缩略图可点击，将对应引用插入提示词。

满参慢速版768p支持“仅尾帧”：把一张图片连接到视频节点的“首尾帧”输入口，模式选择“仅尾帧”，该图片就作为结束画面。不要同时连接普通素材；切换模式不会自动删除已有连线。能力受限768p只提供6/10/15秒，不提供首尾帧选项。能力受限768p显示¥1.50/次，改变秒数不改变其单次费用；满参慢速版768p按秒估算（¥0.10×秒数），改变秒数会改变估算。

任务完成后，“下载成片”将视频放入本地素材库，供预览和后续连线；“保存到电脑”另存为 MP4/WebM 文件。项目自动保存在当前浏览器，切回项目后恢复已有任务查询，不重新创建任务。刷新页面后需重新输入密钥。

左侧任务列表也可独立查询、下载、预览、保存和找回节点。移除画布节点不等于取消上游任务；原任务和未确认提交记录会保留。完成后点击“创建新版本”，会复制草稿和参考连线，保留原节点及成片，不自动发起付费生成。如需复用同一节点，可点“脱离节点”，原任务仍可从任务列表访问。

同一浏览器的同源标签页对同一项目、同一节点使用 Web Locks 和持久化记录防重；不支持 Web Locks 的浏览器会拒绝创建，建议使用当前版 Chrome。排队等待提交锁期间切换项目、密钥，或修改草稿和连线，会中止尚未发送的这次点击，确认后需重新提交。不同节点可独立工作，不锁整个账户。

桌面布局：顶栏直接进入画布、分镜、导演台和剪辑，右侧提供助手及导出；“项目”菜单管理新建、重命名、项目中心、工作区和导入。左侧“创建／素材／工作流／任务”切换浮动面板，素材面板可打开完整素材库。底部提供撤销、缩放、适配视图、节点搜索和面板开关；选择节点后显示操作条与独立占宽的参数检查器，费用和任务操作位于检查器底部。折叠检查器会保留尚未提交的参数，新增节点后自动收起创建面板，避免遮挡连线端口；节点排列和适配视图按实际卡片尺寸计算。黑白主题均以桌面使用为本轮验收范围。

画布支持多选、拖动、分组、保护节点、撤销、复制粘贴、搜索和适配视图。文本节点可作为手动提示词，也可选择当前密钥允许的文本模型；生图节点支持本站 image2.5 文生图与单图编辑，编辑参考图上限 30MiB。

同一项目被多个标签修改时，保存会检测版本冲突并提示处理。可保留本地副本后加载最新版本，或明确选择覆盖；保存失败仍保留本地修改。项目切换时的旧异步操作不能写入新项目，未确认的生成记录不会因保存失败自动解除保护。

分镜支持 2/4/9/12/25 格、剧本导入和十二字段编辑；每镜可建立图片与视频节点。分镜卡片显示预览、时长和镜头内容，导入、AI 拆分与导出入口折叠在顶部工具区。分镜生成的视频节点按当前密钥可用型号和镜头时长选择，H3支持首尾帧的型号单图接首帧、能力受限768p单图接普通素材、SD 单图接素材参考、Wan 单图接单图模式。不能满足时长的型号会明确拒绝，不静默改秒数。

工作流按连线依赖运行，可用 CSV 批量填充，开始前展示费用估算与预算上限。未知价格需要补充估算，不能按免费执行；到达预算会暂停，未确认的生成不会自动重放。文本和图片接口不承诺视频接口的 24 小时幂等：结果不明时保留操作记录，人工核对后才能重试。

导演台已恢复：可编辑 3D 场景、保存并重开，导出参考图片和视频到素材库。AI 运镜先通过本站文本模型形成方案，检查后再应用到场景；不在导演台中保存密钥。素材库支持分类、标签、合集，以及裁切、翻转、旋转和文字叠加，编辑结果另存为新素材。

时间线支持视频、图片叠加、音乐、配音和字幕轨道，可修剪、分割、变速、调音量并导出成片。点击时间标尺定位播放位置，播放头跟随预览，可随时回到开头；选择片段后在下方编辑参数。本机 FFmpeg 使用 H.264/AAC 输出 MP4；也可选择浏览器导出。导出失败会保留工程；缺失素材或不能烧录字幕时会明确提示，只有确认省略后才继续。可另导出 SRT、EDL、OTIO 子集，当前不提供 Premiere 或剪映专用工程。

普通 JSON 导出不包含素材文件；时间线菜单“导出项目包”可将工程、素材和导演台资源一起打包，换机时选择“导入项目包”。缺失素材会列出，不能把不完整工程冒充完整备份。项目版本与模板可在本地管理；账号工作区和跨电脑共享尚未上线。本轮生成验收使用模拟接口，未新增付费任务验证真实上游成片。

导出是项目恢复文件，可能包含原始请求体中的临时素材地址，应自行保管。导入失败保持原项目；未确认提交的保护和重试等待时间会随导入保留。恢复快照缺素材时明确阻止提交，不会自动减少参考素材后生成。

## 1. 接口面（画布代理口径）

画布本机服务把 `/site/*` 固定转发到 `https://xingpan.site/*`（去 `/site` 前缀），不接受查询参数、不跟随重定向、不转发任意地址：

| 操作 | 画布内地址 | 说明 |
|---|---|---|
| 本密钥可用型号 | `GET /site/v1/models` | 按当前 Key 过滤后的型号列表 |
| 上传素材 | `POST /site/reference-assets` | 原始文件字节（非 JSON/Base64/multipart） |
| 创建任务 | `POST /site/v1/videos` | JSON；**必须** `Idempotency-Key` 头 |
| 查询任务 | `GET /site/v1/videos/{id}` | id 取自创建响应 |
| 下载成片 | `GET /site/v1/videos/{id}/content` | 鉴权；支持单段 `Range: bytes=a-b` |
| 文本生成 | `POST /site/v1/chat/completions` | 非流式，明确输出长度上限 |
| 生图 | `POST /site/v1/images/generations` | 本站 image2.5，单张，返回 `b64_json` |
| 参考图编辑 | `POST /site/v1/images/edits` | 仅一张 PNG/JPEG/WebP 参考图，最大 30MiB |

所有请求带 `Authorization: Bearer <API Key>`。Key 只保存在页面内存：不硬编码、不写 localStorage/项目文件/导出文件、不进日志、不放 URL。`/api/pricing` 是登录态报价接口（无 `/v1`），普通 API Key 不一定拿到全部报价——画布用能力表标准单价做估算并注明。

## 2. 素材规则

- 通用上传类型/大小：图片 PNG/JPEG/WebP ≤30MiB；视频 MP4/WebM ≤100MiB；音频 MP3/WAV/M4A ≤30MiB。型号声明更严格限制时同时满足型号限制，不能只按通用上限判断。
- 满参慢速版768p：图片≤30MB、视频≤50MB且只收MP4、音频≤15MB，具体格式按能力表`media_content_types`。这里MB按1,000,000字节计算。上传前检查素材格式与大小；旧素材缺少这些信息时，须重新绑定文件，不能跳过校验。
- 上传返回 `{url, expires_at, duration_seconds?}`；素材有效期 24 小时。
- **全部上传成功才创建一次任务**；任一失败或用户取消 → 不创建、保留草稿。并发上传 ≤3。
- 也可用公网可访问的 HTTPS 素材直链；本机路径、需 Cookie 的地址不行。
- 素材数量按型号 `reference_limits`（分项与合计同时满足）；SD 参考视频合计时长向上取整 ≤30 秒（服务端检测）。
- 满参慢速版768p参考视频、音频每条均为2–15秒，视频合计≤15秒、音频合计≤15秒。上传后只用服务端返回的`duration_seconds`校验；缺少时长、单条或合计越界时不创建任务。页面本地时长不能代替该校验，过期上传记录须重新上传。
- H3按秒档和能力受限768p不能只有音频参考（须同时有图或视频）。

## 3. 模式与字段映射

`metadata.mode` 与能力表 `capability_modes` 词表不同，按 `request_modes` 发送：

| 用户意图 | H3 | SD | Wan |
|---|---|---|---|
| 纯文字 | `text_to_video` | `references`（可空素材） | `text_to_video` |
| 单图 | `frames` + `first_frame_url` | `references` + `image_urls[1]` | `image_to_video` + `image_urls[1]` |
| 多素材参考 | `omni_reference` | `references` | `omni_reference` |
| 首尾帧 | `frames` + `first_frame_url`+`last_frame_url` | `frames` + 双帧 | 不支持 |
| 仅尾帧 | 仅满参慢速版：`frames` + `last_frame_url` | 不支持 | 不支持 |

- 普通素材数组：`metadata.image_urls` / `video_urls` / `audio_urls`（字符串数组，有序）。
- 上表H3单图与首尾帧映射适用于支持frames的型号；能力受限768p的单图使用`omni_reference` + `image_urls[1]`，不支持任何首尾帧模式。
- 首尾帧只发 `first_frame_url` / `last_frame_url`，**不得同时发普通数组**。SD 双帧必须齐全；H3按秒档可只有首帧、不可只有尾帧。满参慢速版“首帧 / 首尾帧”按连接顺序使用首帧、尾帧；“仅尾帧”要求frames口恰好一张图片，只发送`last_frame_url`，不发送首帧或普通参考数组。
- H3按秒档 frames 模式画幅随素材自适应，填 `16:9` 也不承诺固定裁切；要固定构图先裁好输入图。
- `generate_audio` / `face_mode` 仅 SD 稳定/折扣与 Wan（仅 generate_audio）支持，布尔值；不支持的型号（H3、SD 特殊）**连显式 false 都不发**——隐藏控件后不得继续带上旧值。
- `seconds` 整数秒，按型号 `seconds.min/max` 以及存在时的 `allowed_seconds` 校验；`ratio` 必须在型号白名单内，未填默认 `16:9`（H3 另有 `auto`）。
- prompt 字符上限：H3按秒档60000、能力受限768p与满参慢速版768p 7000、SD 稳定 60000、SD 折扣/特殊 5000、Wan 32000。
- 提示词在原文和素材引用规范化后均检查字符上限，避免引用序号变化后超出接口限制。

## 4. 创建与幂等（关键差异：Portal 未传键，画布必须传）

```
创建前：生成 Idempotency-Key（建议 UUID，≤200字符可见ASCII）
        → 持久化 {key, model, 完整body字节, keyFingerprint, createdAt}
POST  → 带 Authorization + Idempotency-Key + 原样 body
成功  → 保存 task id ↔ key 映射，开始轮询
不确定（断网/超时/5xx/429）→ 只能以同一 Key+同一 API Key+同 model+完全同 body 重试 POST；
        已有任务 ID → 一律改走 GET 原任务
窗口  → 显式键保护 24 小时（自首次受理）；未传键自动去重仅 15 分钟，生产不可用
超窗/首次受理不明 → 不盲目重建，查询原任务或联系支持
```

GET 重试与 POST 重试是两条路径：查询/下载失败 → 退避重试同一 GET；创建失败且无任务 ID → 才考虑同键重发 POST。

`Retry-After` 从收到响应时起计算等待截止时间，并随待确认记录持久化。超过 24 小时的未确认记录仍保留保护，导入、重开或停止本地跟踪均不把它自动转换成一笔新的创建请求。

## 5. 任务状态与下载

- `status`: `queued` → `in_progress` → `completed` / `failed` / `cancelled`；`progress` 不是剩余时间承诺。
- `delivery_status=delivering` 表示正在保存/校验成片，**不是可下载**；可下载须 `completed` 且 `delivery_status=ready`（字段可能缺失，需兼容）。
- `download_expired` / `delivery_status=expired` → 停止等待，文件已过期（成片缓存 24 小时）。
- 关闭页面/AbortController 只停止本地等待，不取消后台任务；重开页面用已存任务 ID 恢复轮询。
- 完整下载：带 Bearer 请求 → 校验 HTTP 200，或经 `Content-Range` 与实收字节确认覆盖全文的 206，且 `Content-Type` 为 `video/mp4`/`video/webm` 才存成片。未请求分段时不能把局部 206 当成成片；声明长度与实收不符、JSON/HTML 错误体均拒绝。Blob 通过 `URL.createObjectURL` 预览，密钥不进 URL。
- 错误：`400` 按型号修正参数；`409 idempotency_conflict` 同键不同体；下载 `409 task_not_ready`/`503 video_delivering` 继续等；`410 video_download_expired` 停止；`429/5xx` 遵循 `Retry-After` 退避。

## 6. 画布行为约定

- 型号切换保留 prompt 与全部素材；超出新型号上限的素材标红并阻止提交，不截断不静默丢弃。
- 每个型号记住独立参数选择；首次进入用自身默认值；清晰度由型号决定（无 resolution 控件）。
- 费用预估：型号 `billing_unit=request` 时使用 `price_cny_per_request`，其余使用 `price_cny_per_second × seconds`，标注"标准价估算，专属分组以账户为准"。
- 提交前用 `GET /site/v1/models` 确认型号对当前密钥可用（视频专线分组差异）。

## 7. 最小完整示例

```json
POST /site/v1/videos
Authorization: Bearer <key>  ·  Idempotency-Key: 7d3e1c2a-…-persisted
{
  "model": "seedance-2.5-vip-720p",
  "prompt": "保持@图片1的人物外观，沿走廊缓慢前进，镜头缓慢推近。",
  "seconds": 8,
  "metadata": {
    "ratio": "16:9",
    "mode": "references",
    "image_urls": ["https://…/person.png"],
    "generate_audio": true
  }
}
```

```json
POST /site/v1/videos
{
  "model": "minimax-h3-2k-per-second",
  "prompt": "从首帧平滑过渡到尾帧，保持人物与场景一致。",
  "seconds": 5,
  "metadata": {
    "ratio": "auto",
    "mode": "frames",
    "first_frame_url": "https://…/start.png",
    "last_frame_url": "https://…/end.png"
  }
}
```
