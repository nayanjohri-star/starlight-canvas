# 星盘智能画布（Smart Canvas）

桌面端视频创作工作台：剧本导入 → 分镜 → 角色、场景、道具素材复用 → 生成节点 → 受控批量执行 → 任务恢复 → 成片下载 → 时间线剪辑 → 视频导出与可移植工程包。

- 版本：见 `package.json`（当前 0.5.x）；页面顶栏显示前端构建版本，本机服务版本不一致时会提示
- 各版本说明：`docs/canvas-release/`（0.5 见 `docs/canvas-release/0.5/`：发布说明、核心合同、安全与托管评估、计费口径冲突记录）
- 视频模型接入规范：仓库根目录 `docs/星盘AI_画布视频适配规范.md`、`docs/星盘AI_视频模型接入指南.md`

## 提示词与参考素材

选中图片或视频生成节点后，在节点旁直接编辑提示词和常用参数；需要持续查看时可点「固定到右侧」，小屏幕沿用抽屉编辑。

将图片、视频或音频拖入画布，点击「+ 参考素材」添加素材并建立连线。输入 `@` 只查找已连接素材，支持按 `@图片1` 编号或名称搜索、方向键选择、Enter 插入、Esc/Tab 关闭。选择不上传、不生成、不扣费。图片最多支持 8 张参考图、合计 30MiB；视频首尾帧模式使用原首尾帧输入口。已引用素材可预览和替换，图片节点支持放大编辑、拖动窗口右下角缩放和克隆。

引用失效会阻止新提交，不会自动改指其他素材。参数栏显示标准价估算，真正发起请求仍需点击生成按钮。「节点内预览」只改变成片展示方式，不会提交生成。

## 运行

开发与验收使用 Node.js v24，其他版本未验证。

```bash
npm ci --prefix frontend/director
cd frontend/canvas
npm ci
npm run build
npm start
```

浏览器打开 `http://127.0.0.1:4178`，点击右上角「未设密钥」配置 API 服务商。

- 默认可使用本站；自部署本机版也可添加外部服务商，填写 HTTPS 地址、密钥和型号，本机模型服务允许 HTTP。
- 支持 OpenAI 兼容的同步文本、base64 图片及 multipart 图片编辑；画布兼容接口可显式启用视频合同。
- 地址和型号保存在当前浏览器，密钥仅保存在页面内存中，不写入磁盘、工程导出或日志；刷新后需重新填写密钥。
- 原任务绑定 API 地址、协议和密钥指纹；切换服务商会暂停旧任务，切回原配置可继续查询。
- 外部调用按该服务商价格收费，不采用本站报价；接口返回结果不明时，不自动重复生成。
- 端口通过 `CANVAS_PORT` 修改。本机服务仅监听 `127.0.0.1`，不得直接作为公网多用户服务。

独立源码包的安装、接口范围、许可证及贡献说明见 [社区版说明](docs/open-source/README.md)。

## 两种运行形态

- **本机版**（默认）：`npm run build` 后 `npm start`，页面在 `http://127.0.0.1:4178`，通过本机服务 `/site` 代理访问所选 API 服务商。
- **托管网页版**：`node scripts/build.mjs --mode hosted` 生成 `dist-hosted/`（基础路径 `/canvas/`、API 根 `/canvas-api`）。它由站点的 canvas-web 静态服务与托管 API 适配层提供，不使用本机服务。发布物用 `node scripts/package-hosted.mjs --require-clean --gate-report <report.json> --out <目录>` 生成；CI 在严格门禁通过后会自动生成。托管版的项目只保存在访客浏览器中，请提醒用户用工程包备份。

## 测试

所有测试只访问本机模拟上游，不会发出真实生成请求，也不会产生费用。

```bash
npm run test:env          # 检查环境：浏览器、FFmpeg、导演台资源
npm test                  # 单元与服务端（等同 test:unit）
npm run test:contract     # 能力合同
npm run test:recovery     # 升级、导入与恢复
npm run test:accept       # 独立验收与故障注入
npm run test:e2e          # 浏览器端到端（默认最多 4 个浏览器并发，可用 CANVAS_BROWSER_CONCURRENCY 调整）
npm run test:performance  # 大画布性能
npm run test:package      # 构建产物核验
npm run verify:release    # 依次执行全部层级，并汇总退出码与结果
npm run verify:release:strict  # 严格发布门禁：构建一次、逐层显式必需文件、只允许登记的跳过、测试进程禁止非回环出站，报告写到 .release-evidence/
```

发布包：门禁通过后执行 `node scripts/package-release.mjs --require-clean --archive`，产物在 `release-packages/`（带 SHA256SUMS 与运行说明；不会重新构建，dist 与 build.json 不一致时拒绝打包）。

浏览器测试需要 Chromium：

- 推荐执行 `npx playwright-core install chromium`（有一个用例固定使用 Playwright 管理的浏览器）；
- 也可以用环境变量 `CANVAS_E2E_CHROME` 指定本机 Chrome 或 Chromium 的路径。

导出视频相关的用例需要 `ffmpeg` / `ffprobe` 在 PATH 中：普通测试命令里缺失时标注为未验收；严格发布门禁中缺失即失败。只有显式登记的旧本机插件可选测试允许缺资源退出 77；本站托管导演台的必需测试缺资源、零测试、失败或跳过均阻断发布。

## 协作约定

- 修改任务、下载、恢复、批量执行相关代码时，要保持以下约束：
  - 任务结果不得写入已绑定其他任务的节点；
  - 提交结果不明时不得换新幂等键重新提交；
  - 下载或交付失败时恢复原任务，不能重新生成；
  - 空选择不等于运行全画布；
  - 导入与恢复不得自动发起生成。

  这些约束都有对应的回归测试，不要通过删除断言或增加跳过来让测试通过。
- 不要提交 API Key、`node_modules/`、`dist/`、`tests/shots/`、日志或本地调试脚本（`.gitignore` 已排除）。

## 独立开源候选包

运行 `node scripts/package-open-source.mjs --out release-packages/community-candidate`，生成新的源码目录、ZIP 和 SHA-256。它按允许范围包含画布、导演台及构建所需合同/许可，不复制生产后台、秘密文件、客户数据或 Git 历史；发现常见凭据格式时拒绝打包且只报告位置。候选目录不可覆盖，新的候选需使用新名称。

许可为 AGPL-3.0-or-later，第三方内容保留各自许可证。源码包标为未公开候选；公开前应核对许可/素材、完成独立安装验证，并建立能明确追溯的发布版本。整站生产门禁与社区测试有不同范围。
