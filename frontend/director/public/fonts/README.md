SIL Open Font License 1.1, which permits bundling them with software provided
each copy carries the copyright notice and the licence. Those are the two
`-OFL.txt` files here; keep them alongside the fonts.

Both are subsets. Under OFL a modified copy may not use the Reserved Font Name,
so if a subset is ever renamed or edited beyond subsetting, check clause 3 before
shipping it.
