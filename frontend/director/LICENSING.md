Public License, version 3 or later (`AGPL-3.0-or-later`). The complete license
text is in [`LICENSE`](LICENSE).

If you modify CozyClay and let users interact with that modified version over
a network, section 13 of the AGPL requires you to offer those users the
Corresponding Source of the version you run, at no charge. CozyClay keeps that
offer visible in the Studio footer as **Source code (AGPL)**.

The official build points that link at this repository. Operators deploying a
modified version must set `VITE_SOURCE_CODE_URL` at build time to a public URL
containing the complete Corresponding Source for the version they run.
