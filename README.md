# 星盘智能画布 · 社区测试版

在节点画布里编写提示词、连接参考素材、生成图片与视频，整理分镜和时间线。支持保存项目、导出工程包和恢复已有视频任务。集成的 CozyClay 导演台保留其上游许可证和版权说明。

社区源码仓库：[nayanjohri-star/starlight-canvas](https://github.com/nayanjohri-star/starlight-canvas)。当前为 Beta，适合个人本机自部署。

## 星盘中转与在线体验

**星盘中转站：[https://xingpan.site](https://xingpan.site)**

可以在中转站查看模型价格、使用文档、管理账户及 API 密钥。自部署画布默认提供「星盘」服务商，填写本站 API 密钥即可使用本站已开放的模型和渠道；也可以配置其他兼容 API。模型调用按所选服务商计费。

`SOURCE-VERSION.json` 记录发布文件的 SHA-256 和导入来源。`sourceCommit`、`sourceDirty` 描述内部开发基线，公开版本以本仓库的提交和发布标签为准。

## 安装和启动

需要 Node.js 24 和 npm。下载 [Release 源码包](https://github.com/nayanjohri-star/starlight-canvas/releases)，或克隆仓库：

```sh
git clone https://github.com/nayanjohri-star/starlight-canvas.git
cd starlight-canvas
```

在仓库或解压后的根目录运行：

```sh
npm run setup
npm run build
npm start
```

用 Chrome 打开 `http://127.0.0.1:4178`。右上角「未设密钥」打开 API 设置。安装会下载公开 npm 依赖，构建和启动不会调用生成 API。

服务默认只监听本机，适合个人电脑及 SSH 本地转发使用。它不是可直接向多人开放的账户服务器；公网多用户部署还需要身份、存储隔离与访问控制。本站托管版仍使用本站账户和渠道。

## 使用自己的 API

在 API 服务商下选择「添加服务商」，填写名称、地址、协议和密钥。地址可填写 `https://api.example.com` 或 `https://api.example.com/v1`，也支持带路径前缀的网关。本机模型服务可以填写 `http://127.0.0.1:11434/v1`。

| 协议 | 支持范围 |
| --- | --- |
| OpenAI 兼容 | `/v1/models`、同步 `/v1/chat/completions`、返回 base64 图片的 `/v1/images/generations`；图片编辑会转换为标准 multipart 上传 |
| 画布兼容 | 本站 Image 2.5 请求格式；显式启用视频后支持固定视频能力表对应的上传、创建、查询、下载和取消协议 |

文本型号自动从目录识别，也可每行手动填一个型号。图片支持 GPT Image 风格的 base64 接口；手动填写别名可用于兼容网关。GPT Image 发送标准参数，编辑支持最多 8 张参考图、合计 30 MiB。兼容模式提供 1024×1024、1536×1024、1024×1536，实际支持情况以服务商为准。

不提供 `/v1/models` 的服务商可在目录返回 404/405 时使用手动型号；这表示采用用户配置，不能证明密钥或生成能力已经验证。DALL-E 参考图编辑、仅返回图片 URL 的接口、Anthropic/Gemini 原生协议及其他供应商的视频协议尚未适配。遇到只返回 URL 的图片结果，请在网关提供 base64 返回；画布会保留结果未确认记录，不自动再生成。

画布兼容的视频接口须实现 `reference-assets`、`/v1/videos`、任务查询和成片下载，并保持同一幂等键的重复提交返回同一任务。只拥有 `/v1/videos` 路径不代表满足这些要求。具体字段和能力见 `frontend/canvas/contracts/`，接入新的视频供应商需增加适配器。

地址与型号保存在当前浏览器，密钥仅存页面内存，不写入磁盘、导出或日志。刷新后重新填写密钥。每次新请求使用当前服务商；原任务绑定地址、协议和密钥指纹，切换服务商会暂停旧任务，切回原配置可继续查询。不同服务商之间不会自动重试。

外部调用由对应服务商收费。画布不会套用本站报价，未知价格显示未知；手动预算只是估算。测试均使用模拟接口，不产生生成费用。

## 日常操作

- 「+ 参考素材」添加素材并连线；提示词里的 `@` 只选择已经连接的素材。
- 已引用素材可预览、替换；悬停可放大查看。输入完整 `@图片1` 可以按编号查找。
- 图片生成窗口支持拖动右下角改变大小、放大编辑及克隆节点；克隆不会发起生成。
- 工程包用于迁移素材和项目。浏览器存储不是跨设备备份，请定期导出。
- 视频任务恢复查询和下载原任务；同步文本、外部图片调用遇到刷新或连接中断时可能无法自动取回结果，需要核对服务商记录。结果不明时节点锁定，避免重复扣费。

## 本机导出

视频编码需要 `ffmpeg` 和 `ffprobe` 在 PATH 中。可先正常使用画布，准备导出时再安装。旧 MiniMax 本机插件未分发；缺插件不影响节点画布、图片和文本生成。导演台及字体随本包提供，它保留自己的独立许可说明。
